# Галерист — шаблон арт-галереи

![Preview](https://cdn.poehali.dev/templates/artiste-ru/preview-ru.jpg)

Элегантный лендинг для арт-галереи с секциями художников, типов искусства и выставочных пространств.

## Технологии

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Radix UI
- Lucide Icons

## Быстрый старт

```bash
npm install
npm run dev
```

## Теги

`галерея` `искусство` `художники` `портфолио` `лендинг` `выставка` `культура` `арт`
